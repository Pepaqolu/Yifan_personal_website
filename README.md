# Yifan Fu — Personal Website

A production-ready personal brand and China market advisory website built with Next.js, TypeScript, Tailwind CSS, and Motion.

## Editing content

All personal details and website copy live in `src/content/site.ts`. Replace values marked `TODO` only with verified information.

## Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
pnpm build
pnpm start
```

The project can be deployed directly to Vercel with the standard Next.js preset.
